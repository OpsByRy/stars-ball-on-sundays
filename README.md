# Stars Ball On Sundays · public research website

This is the public presentation of SBOS's reviewed basketball research and recorded outcomes. It contains the website, brand assets, dated publication records with saved probabilities and projections, and standard odds/result utilities. Layups and Lobs show the approved selections beside Ry’s favorites. Bench is the depth chart of review-only props and stays outside official selection totals and hit/miss records. SBOS Research also includes reviewed Not a Pick lines. Same-day price updates append a new edition, retain earlier snapshots and label unavailable prices or changed value checks. The proprietary research engine, raw source candidate data, training data, calculation rules, and internal evaluations are maintained separately.

Run `python3 scripts/build.py` to validate every publication and build `dist/`. Preview only that directory with `python3 -m http.server 8001 --directory dist --bind 127.0.0.1`. Run `python3 -m unittest discover -s tests` and `node --test tests/*.test.cjs` before publishing. No API key or paid data connection is needed to build this website.

Only files listed in `site-manifest.json` and validated edition records are deployed. Data accepts a small explicit schema, rejects unknown fields at every nesting level, verifies content hashes, and includes box-score identities only for published selections. Never copy an engine checkout, raw slate export, CSV, technical handoff, diagnostic report, or research screenshot into this repository.

The public record distinguishes Ry's personal favorites from exploratory SBOS research. Missing original publication times remain unavailable. Statistical outcomes do not verify sportsbook settlement or establish profitability. See [About SBOS](https://opsbyry.github.io/stars-ball-on-sundays/about/) and the [evidence and results guide](https://opsbyry.github.io/stars-ball-on-sundays/guide/).

Research updates arrive as reviewed, sanitized records from the private publisher. Public code does not generate selections or infer model scores. The optional result refresher only checks already published contracts against public box scores; it cannot collect sportsbook odds or run the research algorithm.

Daily Board uses one tabbed list for All Daily Picks, Layups and Lobs, with a separate Ry’s Favorites filter. Essential search, probability and sorting controls stay visible; game, team and stat filters expand on demand. Research and Ry’s posted parlays have separate routes. Links preserve the board date and filter state, and the calculator keeps its selections within the browser session for each date.

The build derives small `data/boards/` views from the latest validated daily editions. These contain the selected props and personal attribution rows, with a `sourceVersion` pointing to the complete immutable edition. The separate Research page fetches the complete edition, including Not a Pick rows. Derived views never rewrite edition files or recalculate selections, prices, estimates or results.

Parlays uses a compact tabbed board for All Parlays, Plus Money and Longshots. Search and combined filters operate only on saved tickets; no list is truncated. Leg-estimate filters require every leg to meet the minimum and do not imply a joint win probability. Optional publisher-owned `ryFavorite` flags identify Ry’s favorite tickets; leg favorites do not automatically flag a parlay. Book preference reprices the same exact legs.

The Same Game Parlays filter covers saved same-game and mixed-game SGP combinations when reviewed tickets are available. The calculator accepts a user-entered full-ticket quote and clearly labeled probability scenarios. Straight-odds multiplication is only an independent benchmark; a quote gap is not a proof of value. Calculator assumptions are not validated SBOS joint forecasts, and no unvalidated research candidate is promoted into a published pick.
